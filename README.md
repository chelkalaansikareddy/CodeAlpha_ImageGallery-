# 🖼️ **CodeAlpha Image Gallery**

A beautiful and responsive **Image Gallery website** developed using **HTML, CSS, and JavaScript** as part of the CodeAlpha Internship. 🚀

## ✨ **Features**

- 🖼️ Responsive image gallery
- 🎨 Clean and attractive user interface
- 📱 Mobile-friendly design
- 🔍 Interactive image viewing
- ⚡ Smooth and simple user experience

## 🛠️ **Technologies Used**

- 🌐 **HTML**
- 🎨 **CSS**
- ⚙️ **JavaScript**

## 🎯 **Project Purpose**

This project was created to practice **frontend web development** concepts such as HTML structure, CSS styling, responsive design, and JavaScript interactivity. 💻
